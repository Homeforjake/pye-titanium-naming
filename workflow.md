# PYE Naming Workflow — поиск новых названий

## Фаза 1: Бриф

Перед генерацией нужно зафиксировать вводные:

- [ ] **Линейка** — Forms / Sunnies / Bolds / Chains / Overlay / новая?
- [ ] **Количество имён** — сколько нужно (с запасом, обычно x3 от финала)
- [ ] **Характер модели** — форма, настроение, аудитория (м/ж/унисекс)
- [ ] **Ограничения** — что точно НЕ хотим (длинные, сложные, похожие на конкурентов)
- [ ] **Референсы настроения** — какие из старых имён "попали в точку"?

## Фаза 2: Генерация (расходимся)

Здесь цель — набрать как можно больше вариантов, не фильтруя.

### Подходы для генерации:

**1. По категориям (проверенный паттерн PYE):**
- Имена людей: редкие, винтажные, мультикультурные
- Географические: малоизвестные красивые места
- Поп-культура: персонажи, фильмы, музыка
- Природа: минералы, растения, погодные явления
- Характер: прилагательные, черты

**2. По звучанию:**
- Односложные (как Wax, Kif, Arc)
- Двухсложные с ударной первой (как Halo, Mason, Sterling)
- С мягким окончанием (как Boketto, Como, Shuya)

**3. По ассоциации:**
- Взять 5 любимых старых имён → свободные ассоциации от каждого
- Mood board → имена, которые "звучат как" картинка

**4. AI-генерация:**
- Дать Claude/ChatGPT бриф + референсы + антипримеры
- Попросить 50–100 вариантов в нескольких "волнах"
- Каждая волна — с обратной связью по предыдущей

## Фаза 3: Фильтрация (сходимся)

### Быстрый отсев — убираем если:
- [ ] Уже есть в `reference-names.md`
- [ ] Совпадает с известным брендом очков (Ray-Ban, Oakley и т.д. — модели)
- [ ] Сложно произнести / написать
- [ ] Плохие ассоциации на русском или английском
- [ ] Слишком длинное (>10 букв)

### Скоринг финалистов (1–5 по каждому):
| Критерий | Вес |
|----------|-----|
| Запоминаемость | ×3 |
| Звучание вслух | ×2 |
| Вписывается в стиль PYE | ×2 |
| Визуальная красота (как выглядит на дужке) | ×2 |
| Уникальность (Google/trademark) | ×1 |

## Фаза 4: Валидация

- [ ] Проверка через Google: нет ли негативных ассоциаций
- [ ] Проверка trademark (ФИПС / WIPO / USPTO)
- [ ] Тест на дужке — как выглядит гравировка
- [ ] Опрос команды / близких (слепой тест: "какая модель дороже?")

## Как работать со мной (AI)

1. **Скажи бриф** — линейка, характер, сколько имён, любимые примеры
2. **Я генерирую волну** — 30–50 имён с короткими пояснениями
3. **Ты даёшь feedback** — "вот эти 5 в точку, вот эти мимо, хочу больше такого"
4. **Я уточняю следующую волну** — с учётом обратной связи
5. **Повторяем** пока не наберём нужное количество финалистов
6. **Скорим и валидируем** вместе
