# Premium Titanium Eyewear: Model Naming Patterns Analysis

## Research Scope
Analysis of 9 premium titanium/craftsman eyewear brands: model names, naming strategies, distinctive traits, price context, and synthesis for PYE Optics positioning.

---

# 1. JACQUES MARIE MAGE
**Positioning:** Ultra-premium, cult following, limited editions (max 500 pairs/design)

## Model Names (30+)
Alfie, Alfred, Alin, Amelia, Ann, Atkins, Ascari, Bolin, Bugsy, Challenger, Chelsea, Corniche, Dasan, Dealan, Dealan 53, Duke, Earl, Enzo, Fellini, Fugue, GT-R, Hatfield, Jeff, Fly, Jagger, Krasner, Molino, Molino 55, Pat, Peyote, Reynolds, Taos, Torino, Walker, Zephirin  
*Collaborations:* Fontainebleau, Duke, Peyote (Hunter S. Thompson), Mont Blanc (White Mountaineering)

## Naming Pattern
- **Primary:** First names (often male), cinematic/cultural references
- **Secondary:** Places (Torino, Chelsea, Taos, Corniche), automotive (GT-R, Ascari), artists (Krasner, Fellini)
- **Variants:** Size suffixes (Dealan 53, Molino 55)

## Distinctive
- Strong male first-name bias (Alfred, Enzo, Walker, Jagger)
- Film/culture ties (Fellini, Dennis Hopper/Taos, Bugsy Siegel)
- Italian/French flavor (Enzo, Fellini, Zephirin, Corniche)
- No numbers except size variants
- Names feel like characters, not products

## Price Range
**$840–$1,900 USD** (most $960–$1,185; special editions higher)

# SYNTHESIS

## Common Patterns Across Premium Brands

| Pattern | Brands Using | Notes |
|--------|--------------|-------|
| **Human first names** | JMM, Garrett Leight | Feels personal, character-driven |
| **Surnames** | JMM, Native Sons, MYKITA | Authority, heritage, identity |
| **Place names** | JMM, Garrett Leight, MYKITA | Location = vibe (Naples, Marfa) |
| **Numeric only** | Lindberg, Matsuda, Eyevan, Kuboraum | Systematic, catalog, industrial |
| **Abstract/word + code** | Gentle Monster | Playful, fashion-led |
| **Collections + codes** | Lindberg, MYKITA | Structure first, then SKU |
| **Version numbers** | JMM, Native Sons, Garrett Leight | 55, 53, II, 2.0, EXP |

## Uncommon / Unique Approaches

1. **Eyevan 7285** — Pure numeric archive (139, 1000, 1158); no names at all.
2. **Kuboraum** — Ultra-compact Letter+Number (K3, P2, J73); art-object, not product.
3. **Lindberg** — Collection-led; individual models are invisible numbers.
4. **Gentle Monster** — Food/abstract + codes (Cinnamon T8, Crepe L2); casual, accessible.
5. **JMM** — Strong cinematic/cultural references (Fellini, Ascari, Taos); storytelling.

## Especially Effective Strategies

1. **JMM — Named characters:** Names like Walker, Fellini, Jagger feel like people; emotional connection, memorability.
2. **Native Sons — Surname + culture:** McCLANE, RAYLAN, MURPHY = built-in story for fans.
3. **Garrett Leight — Place + type:** Hampton Sun, Kinney — clear, evocative, consistent.
4. **Eyevan — Pure numbers:** Anti-fashion, craft-first, museum feel; attracts purists.
5. **Kuboraum — Minimal codes:** K3, P2; mysterious, collectible, "if you know you know."

## Whitespace (Approaches Nobody Is Using)

1. **Slavic/Eastern European names** — No brand uses Slavic first or last names (Nikolai, Sasha, Volkov, Orlov).
2. **Short poetic words** — Single evocative words 4–6 letters (Dusk, Haze, Flux, Zephyr); JMM uses longer names.
3. **Transliterated Russian/Japanese** — Cyrillic→Roman or Japanese→Roman as design element.
4. **Architectural/geometry terms** — Arc, Span, Cantilever; design-forward, not common in eyewear.
5. **Mythology (non-Greco-Roman)** — Slavic, Japanese folklore; JMM uses Western references.
6. **Abstract concepts (single word)** — Tranquil, Drift, Still; different from JMM’s character names.
7. **5-letter median** — Most brands skew longer (7–8 chars); few optimize for ~5 letters.

## Recommendations for PYE Optics

**Context:** Russian brand, Japanese titanium, cultural but not pretentious, target median ~5 letters.

### Strategies to Consider

1. **Short Slavic + Japanese hybrid**
   - 4–6 letter names: Volna (wave), Zima (winter), Koto, Yuki, Sasha
   - Avoids JMM/GL place-name fatigue; distinctive for Russia + Japan.

2. **Single evocative words (~5 letters)**
   - Dusk, Haze, Flux, Drift, Still, Frost, Glow, Mist
   - Different from character-name brands; modern, calm.

3. **Transliterated concepts**
   - Russian words (Tishina = silence, Zerkalo = mirror) or Japanese (Yuugen, Shibui)
   - Requires light explanation but supports “cultural” positioning.

4. **Short Letter+Number (Kuboraum-inspired)**
   - P1, V2, K5 — if you want minimal, engineering-led.
   - Risk: can feel cold or copy-like.

5. **Avoid**
   - Long Italian/French names (JMM territory)
   - Irish surnames (Native Sons)
   - American place names (Garrett Leight)
   - Pure 4-digit codes (Matsuda/Eyevan)

### Suggested naming zones for PYE

| Zone | Example names | Rationale |
|------|---------------|-----------|
| **Slavic short** | Volna, Zima, Svet | 4–5 letters, cultural, distinctive |
| **Japanese short** | Koto, Yuki, Hana | 4 letters, nods to titanium/craft |
| **Abstract single word** | Drift, Haze, Flux | 4–5 letters, modern, not character-led |
| **Hybrid** | Volna-K, Yuki 2 | Combines culture + optional variant code |

### Median length target (~5 letters)

- **4 letters:** Volna, Koto, Hana, Flux, Mist
- **5 letters:** Zima, Drift, Frost, Still, Svet
- **6 letters:** Tranquil (stretch), Yuki (4), Zerkalo (longer, concept-driven)
